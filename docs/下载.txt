💡 给 APP 下载模块的实现提醒

· YACL 和 GeckoLib：体积小（1 MB 左右），可以直接硬编码 Modrinth CDN 链接，下载后比对 SHA1/SHA512 即可。
· Verity JE 6：245 MB 左右的大文件，务必实现 HTTP Range 断点续传、分块下载和超时重试。如果通过 CurseForge API 获取正式版链接，注意 downloadUrl 有时效性/重定向，OkHttp 需跟随重定向（默认已支持）。
· 统一校验逻辑：抽象一个 HashType（SHA1 / SHA512 / MD5），Modrinth 优先用 SHA512（更安全），CurseForge 视返回字段而定。下载完成后立即校验，失败则删除重试。
